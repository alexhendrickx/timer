# v1.0.0 — Polish & Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a cross-platform 1.0: an app icon on both platforms, a clean first-run experience, a full end-to-end verification pass on iPhone **and** Mac, polish, and an optional code-signed build.

**Architecture:** No new features. Icon generation for iOS + macOS, a first-run guard that guides adding the first activity, a full manual E2E script driven on both platforms, and build hardening.

**Tech Stack:** `flutter_launcher_icons` (iOS + macOS), the v0.9 stack. Code-signing uses Alex's Apple developer account (optional).

**Spec:** `docs/superpowers/specs/2026-11-02-cross-platform-redesign-design.md`

## Global Constraints

- No behavior changes to tracking / rounding / export / sync. Never lose the exact recorded time. (Spec: Anti-goals)
- Both targets (iPhone + Mac) must launch, track, and sync from the one codebase. (Spec: Platforms)
- Set `pubspec.yaml` `version: 1.0.0+10`.

## Review Focus

- **First launch ever (empty DB, no activities, not signed in):** Home guides the user to add an activity; nothing looks broken; the app is fully usable offline/local. → Task 3 E2E.
- **Full day simulated end-to-end on both platforms:** start/stop sessions across activities, get a break overlay, drill history, see reports, export via the share sheet — numbers reconcile with exact time. → Task 3 E2E.
- **Mac data folder on an external drive absent at launch:** falls back gracefully (v0.1 behavior) and says so. → Task 3 E2E.
- **Cross-device round-trip:** a session made on iPhone shows on Mac and vice-versa after sign-in; a delete propagates. → Task 3 E2E.
