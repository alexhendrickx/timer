# v0.4.0 — Break Reminders Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** While a timer runs, fire a local notification after the work interval suggesting a break, re-arming for the next interval; the intervals are configurable in Settings (default 90 min work / 15 min break).

**Architecture:** A `ReminderScheduler` subscribes to `TimerEngine`. On start it schedules a notification `workInterval` from now; when it fires (or the interval elapses), it re-schedules one interval later. On stop it cancels. Settings persist the two durations via `shared_preferences`.

**Tech Stack:** flutter_local_notifications (macOS), shared_preferences, plus prior stack.

**Spec:** `docs/superpowers/specs/2026-10-31-local-time-tracker-design.md`

## Global Constraints

- Defaults: work 90 min, break 15 min; both editable in Settings. (Spec: Goals)
- Notifications are local only; request macOS notification permission on first use.
- Reminders keep coming on long sessions (re-arm after each fire). (Spec: Behaviour notes)
- Set `pubspec.yaml` `version: 0.4.0+4`.

## Review Focus

- **Timer stopped before the interval elapses:** the pending reminder must be cancelled (no stray notification). → test in Task 2.
- **Settings changed while a timer runs:** next reminder uses the new interval (re-arm on change). → test in Task 2.
- **Interval set to 0 / negative in Settings:** clamp to a sane minimum (e.g. 1 min) or disable; never schedule at/for the past. → test in Task 3.
- **Notification permission denied:** app still tracks time; it surfaces a one-time note, does not crash or block. → manual check in Task 4.

### Task 2: ReminderScheduler

**Files:**
- Create: `lib/feature/tracker/service/reminder_scheduler.dart`
- Create: `lib/feature/settings/data/reminder_settings.dart` (load/save work+break durations)
- Test: `test/feature/reminder_scheduler_test.dart`

**Interfaces:**
- Consumes: `TimerEngine`, `ReminderSettings`, an injectable notifications port `NotificationsPort { Future<void> scheduleAt(DateTime, String title, String body); Future<void> cancelAll(); }`.
- Produces: `class ReminderScheduler`:
  - `void onTimerStarted(DateTime start)` — schedules first reminder at `start + workInterval`.
  - `void onReminderFired(DateTime firedAt)` — re-schedules at `firedAt + workInterval`.
  - `void onTimerStopped()` — cancels all.
  - `void onSettingsChanged()` — re-arms from now using the new interval if running.
- `class ReminderSettings`: `Duration work` (default 90m), `Duration breakLen` (default 15m); `load()`, `save()`.
