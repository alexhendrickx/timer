# v0.8.0 — Export & View-Only Rounding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Export the currently-filtered history through the system share sheet as CSV, a clean printable HTML report, and a formatted PDF — grouped by activity with sum-then-rounded totals and amounts, with an option to emit one file per activity for per-client invoicing — and make the 15-min rounding step a view-only Settings control that flows through totals, reports, and exports.

**Architecture:** Three pure builders turn `(sessions, totals, meta)` into text/bytes: `CsvBuilder`, `HtmlReportBuilder`, `PdfReportBuilder`. An `ExportService` gathers data from `HistoryRepository`, chooses scope (combined vs per-activity, D6), builds the files, and hands them to the OS share sheet (works on iPhone and Mac). The rounding step moves into `RoundingSettings` (persisted), read by `TotalsCalculator`/reports/exports; it is purely a view layer — stored `durationSeconds` is never touched.

**Tech Stack:** `pdf` + `printing`, `share_plus` (system share sheet on iOS + macOS), `shared_preferences`, the v0.7 stack. No new network deps.

**Spec:** `docs/superpowers/specs/2026-11-02-cross-platform-redesign-design.md`

## Global Constraints

- Export scope = the active History filter (activity + date range); offer combined vs one-file-per-activity (D6). (Spec: Export)
- Grouped by activity; totals are sum-then-round (D4) at the Settings step (default 900s); amount when a rate is set. CSV carries **exact** per-session durations; rounding appears only on totals/summary rows. (Spec: Export, Rounding)
- Export goes through the **system share sheet** on both platforms; fully local — no upload. (Spec: Export)
- Rounding is **view-only**: changing the step never alters stored `durationSeconds`. (Spec: Anti-goals)
- Set `pubspec.yaml` `version: 0.8.0+8`.

## Review Focus

- **Notes containing commas / quotes / newlines in CSV:** RFC 4180 quoting, columns not corrupted. → test in Task 3.
- **Activity without a rate in reports/exports:** amount column blank, grand total still correct. → test in Tasks 3–4.
- **Empty export (filter matches nothing):** a valid, well-formed empty file, not a crash. → test in Task 3.
- **Per-activity filename collisions / unsafe characters:** activity name sanitized to a safe filename and de-duplicated. → test in Task 5.
- **Rounded hours vs exact in the summary:** report hours and amounts both derive from the rounded total, never from exact seconds; changing the Settings step changes every rounded figure consistently. → test in Tasks 2 + 4.
