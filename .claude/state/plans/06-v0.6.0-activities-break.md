# v0.6.0 — Adaptive Activity Management & Break Overlay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user create, edit, and archive activities with a platform-adaptive surface (iPhone: long-press a focus card to edit, "+" to add; Mac: a dedicated Activities screen), and gently nudge breaks while a timer runs via a full-screen, easily dismissable overlay that re-arms, with a local-notification fallback when the app is backgrounded.

**Architecture:** A platform-free `ReminderScheduler` subscribes to `TimerEngine`: on start it schedules the next break; when the break is due it shows the full-screen overlay (foreground) and/or posts a local notification (backgrounded), then re-arms one interval later; on stop it cancels. A `NotificationsPort` abstracts the OS; `NotificationsService` implements it for iOS + macOS. Activity editing is one shared `ActivityEditSheet` (name/color/rate/currency/archive) surfaced per platform: a card long-press + "+" on iPhone, a list screen on Mac. The D7 archive-vs-delete guard lives in `ActivityRepository`.

**Tech Stack:** `flutter_local_notifications` (iOS + macOS), `shared_preferences`, the v0.5 stack. No new network deps.

**Spec:** `docs/superpowers/specs/2026-11-02-cross-platform-redesign-design.md`

## Global Constraints

- Break reminder = a full-screen gentle overlay ("Time to stand" style), easily dismissable (tap/swipe); default interval editable in Settings; it re-arms one interval later so long sessions keep getting nudged. (Spec: Reminders)
- When the app is backgrounded (chiefly iOS), the overlay cannot show — fall back to a local notification. (Spec: Reminders, flag)
- Deleting an activity that has sessions is forbidden → archive (D7); hard-delete only at zero sessions. Archived activities are excluded from the launcher; history/totals are preserved. (Spec: Activity management, D7)
- Activity management is platform-adaptive: iPhone long-press card + "+"; Mac dedicated Activities screen. (Spec: Activity management)
- Set `pubspec.yaml` `version: 0.6.0+6`.

## Review Focus

- **Timer stopped before the interval elapses:** the pending reminder/overlay is cancelled (no stray notification or overlay). → test in Task 2.
- **Interval changed in Settings while a timer runs:** the next reminder uses the new interval (re-arm from now). → test in Task 2.
- **Interval set to 0 / negative:** clamped to a sane minimum (≥ 1 min); never scheduled in the past. → test in Task 3.
- **Notification permission denied:** the app still tracks and still shows the in-app overlay when foregrounded; it surfaces a one-time note, never blocks. → manual in Task 6.
- **Attempt to delete an activity that has sessions:** blocked, offered as archive instead, no FK violation. → test in Task 4.
- **Editing the currently-running activity (rename/recolor):** the running screen and card reflect the change; the open session is untouched. → manual in Task 6.

**Interfaces:**
- Consumes: `TimerEngine`, `ReminderSettings`, an injectable `NotificationsPort { Future<void> scheduleAt(DateTime, String title, String body); Future<void> cancelAll(); }`, and an injectable `onBreakDue(DateTime)` callback (the UI shows the overlay).
- Produces:
  - `class ReminderSettings`: `Duration interval` (default 90m); `load()`, `save()` via `shared_preferences`.
  - `class ReminderScheduler`:
    - `void onTimerStarted(DateTime start)` — schedule the first break at `start + interval`.
    - `void onBreakFired(DateTime firedAt)` — fire `onBreakDue`/notification, then re-schedule at `firedAt + interval`.
    - `void onTimerStopped()` — cancel all.
    - `void onSettingsChanged()` — re-arm from now with the new interval if running.

```dart

});
test('firing re-arms another interval later', () {
  scheduler.onBreakFired(DateTime(2026,11,2,10,30));
  expect(fakePort.lastScheduledAt, DateTime(2026,11,2,12,0));
});
test('stop cancels pending reminders', () {
  scheduler.onTimerStopped();
  expect(fakePort.cancelledAll, true);

test('settings change re-arms from now with the new interval', () {
```
