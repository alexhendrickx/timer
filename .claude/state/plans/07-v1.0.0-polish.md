# v1.0.0 — Polish & Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a 1.0: app icon, a clean first-run experience, an end-to-end verification pass of the whole flow, and an optional code-signed/notarized build.

**Architecture:** No new features. Icon generation, a first-run check that the data folder is set, a full manual E2E script, and build hardening.

**Tech Stack:** `flutter_launcher_icons` (macOS), prior stack. Code-signing uses Alex's Apple developer account (optional).

**Spec:** `docs/superpowers/specs/2026-10-31-local-time-tracker-design.md`

## Global Constraints

- No behavior changes to tracking/rounding/export. (Spec: Anti-goals — don't lose exact time.)
- Set `pubspec.yaml` `version: 1.0.0+7`.

## Review Focus

- **First launch ever (empty DB, no activities):** Home guides the user to add an activity; nothing looks broken. → Task 3 E2E.
- **Full day simulated end-to-end:** start/stop several sessions across activities, get a reminder, view history totals, export — numbers reconcile with exact time. → Task 3 E2E.
- **Data folder on an external drive that is absent at launch:** falls back gracefully (v0.1 behavior) and says so. → Task 3 E2E.
