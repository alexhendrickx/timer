# v0.2.0 — Core Tracker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Manage activities, pick one and Start/Stop a live timer that persists sessions, survives app restart, and asks before billing a gap after quit/sleep.

**Architecture:** A `TimerEngine` (ChangeNotifier) owns the single running session: it writes an open `Session` row on start (endTime null), ticks elapsed every second, persists `lastSeenAt` periodically, and closes the row on stop. Repositories wrap drift. UI is a pick-activity dropdown + Start/Stop on Home.

**Tech Stack:** drift (from v0.1), provider, Flutter.

**Spec:** `docs/superpowers/specs/2026-10-31-local-time-tracker-design.md`

## Global Constraints

- One timer at a time (D1). Starting a second while one runs must prompt to stop the first.
- Store exact `durationSeconds`; never round in storage. (Anti-goals)
- No manual/retro entry (D3) — only live start/stop creates sessions; notes editable later (v0.5).
- Set `pubspec.yaml` `version: 0.2.0+2`.

## Review Focus

- **App quit/sleep with a timer running, reopened much later (D2):** must NOT silently extend the session; on resume it offers "keep running" vs "stop at lastSeenAt". → test in Task 3.
- **Start pressed with no activity selected:** Start is disabled / no-op, never creates an orphan session. → test in Task 4.
- **Stop pressed with no running timer:** no-op, no crash. → test in Task 3.
- **Session spanning midnight (D5):** `date` = the start day; duration = full elapsed, attributed to start day. → test in Task 3.
- **Archived activity (v0.5) not selectable:** picker excludes `archived == true`. → test in Task 2.

### Task 3: Session repository + TimerEngine

**Files:**
- Create: `lib/feature/tracker/data/session_repository.dart`
- Create: `lib/feature/tracker/service/timer_engine.dart`
- Test: `test/feature/session_repository_test.dart`, `test/feature/timer_engine_test.dart`

**Interfaces:**
- Consumes: `AppDatabase`, `ActivityRepository`.
- Produces:
  - `class SessionRepository(AppDatabase db)`:
    - `Future<int> startSession({required int activityId, required DateTime start})` — inserts open row (`endTime` null, `date` = `DateUtils.dateOnly(start)`, `lastSeenAt` = start).
    - `Future<void> touch(int sessionId, DateTime seenAt)` — updates `lastSeenAt`.
    - `Future<void> closeSession(int sessionId, DateTime end)` — sets `endTime`, `durationSeconds = end - startTime`.
    - `Future<Session?> openSession()` — the row with `endTime == null`, if any.
  - `class TimerEngine extends ChangeNotifier`:
    - `Session? get running`; `Duration get elapsed`; `Stream<Duration>`/`notifyListeners` each second.
    - `Future<void> start(int activityId)` (throws `StateError` if one already running — UI guards via D1).
    - `Future<void> stop()` (no-op if none running).
    - `Future<ResumeDecision?> detectOrphan()` — on launch, if `openSession()` exists returns a `ResumeDecision` describing start + lastSeenAt; `resumeKeepRunning()` / `resumeStopAtLastSeen()` resolve it.

- [ ] **Step 1: Write failing tests**

```dart

test('session across midnight keeps start day and full duration', () async {
```
