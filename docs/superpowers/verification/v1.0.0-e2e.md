# v1.0.0 — Cross-platform verification

This records the **automatable** part of the v1.0.0 end-to-end pass. The
remaining on-device / Apple-account steps that cannot be run headlessly are
enumerated in `docs/RELEASE-CHECKLIST.md` (the single consolidated manual
checklist) and are **not** repeated here.

## What is NOT verified here (needs Alex, on real devices / Apple account)

Driving the app on a physical iPhone + Mac, cross-device Supabase sync,
Sign in with Apple, the macOS global-hotkey keypress, the iOS Action
button / widget / Siri, notification permission + break flow, chart visual
checks, share-sheet files, and code-signing / notarization **cannot be
exercised from this environment**. They are listed, step by step, in
`docs/RELEASE-CHECKLIST.md`. None of them were simulated or faked.
